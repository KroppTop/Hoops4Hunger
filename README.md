# St. John Hoops for Hunger

Website for the St. John Hoops for Hunger 3v3 Challenge in Berlin, WI. All proceeds and food donations go to the Berlin Food Pantry.

Plain HTML, CSS and JavaScript with no build step. The content mirrors the current site at hoops4hunger.com.

## Pages

| File | Page |
| --- | --- |
| `index.html` | Home: cash purse, tournament structure, registered squads |
| `schedule-rules.html` | Eligibility, uniforms, fouls, Day 1 / Day 2 details, Championship Saturday timeline |
| `register.html` | Team registration form |
| `sponsors.html` | Sponsor tiers and sponsorship contact |

Shared files: `styles.css` (colors and fonts are the variables at the top), `script.js` (mobile menu and registration form), `images/`, `fonts/`.

## Fonts

- **Headings:** Deutsch Gothic by J. Fordyce (1994), self-hosted in `fonts/`. Its license allows free distribution as long as the font file is unaltered and `DEUTSCH.TXT` stays with it, so keep both files as they are.
- **Body text:** Barlow, with Barlow Condensed for labels, buttons and numbers (Google Fonts).

Fonts do not load when a page is opened directly from disk; use the local server below to preview.

The SVGs are generated by `tools/logo/make_logos.py` (text is converted to shapes, so they need no fonts installed). To change the logo, edit that script and run it with Deutsch Gothic (`fonts/Deutsch.ttf`) and Barlow Condensed 600/700 (from the `@fontsource/barlow-condensed` npm package):

```sh
python3 tools/logo/make_logos.py fonts/Deutsch.ttf <barlow-condensed-700.woff2> <barlow-condensed-600.woff2> images/logo site
```

## Common updates

- **Registered teams:** added automatically when a team registers, and shown live under Current Entrants (first 5, the rest in a "See all" dropdown). The list lives in `api/data/teams.json` on the server; edit or remove a team there in hPanel's File Manager. The four teams written in `index.html` show only if the live list can't load.
- **Sponsors:** copy a `sponsor` card in `sponsors.html` and add the logo to `images/`.
- **Dates / deadline:** the "Sign up before April 7!" banner and the dates appear on every page; search for `April` to find them.
- **Header and footer:** repeated in all four pages, so change them in each file.

## Turning on the registration form

When a team submits the form, `api/register.php`:

1. Adds the captain to **Hostinger Reach** as a contact (name, email, phone, and a note with the team name; Reach limits notes to 75 characters, so player heights are in the email only).
2. Emails the full registration to **hello@hoops4hunger.com**, with Reply-To set to the captain, and says whether the Reach step worked.
3. Shows the captain a confirmation message.

If Reach is down or rejects the contact, the registration still goes through and the email tells you to add them by hand. If the server can't be reached at all, the form offers a pre-filled email instead.

### Setup (one time)

1. **Host the site on Hostinger web hosting** (a plan with PHP, such as Premium or Business). Upload everything in this repository to `public_html` using hPanel's File Manager, or connect this GitHub repository with hPanel's Git deployment. A Website Builder-only plan can't run `api/register.php`.
2. **Create the mailbox** hello@hoops4hunger.com in Hostinger Email if it doesn't exist, so registration emails are sent from your own domain.
3. **Generate a Hostinger API token** in hPanel (Hostinger's guide: [How to use the Reach public API](https://www.hostinger.com/support/?p=20452)).
4. **Create the private settings file.** Copy `api/config.sample.php` to `h4h-config.php` in the folder **above** `public_html` and paste in your token. (`api/config.php` also works; `api/.htaccess` blocks it from the web.) Never commit this file; `.gitignore` already excludes it.
5. **Optional:** to tag registrants in Reach (e.g. "2027 Teams"), put the tag's UUID in `reach_tag_uuids`.
6. **Test it:** submit a registration with your own email, then check your inbox (and spam folder, the first time) and your Reach contacts.

If double opt-in is turned on in Reach, captains get a confirmation email and show as "pending" until they confirm.

Server errors are written to the PHP error log in hPanel, prefixed with `[hoops4hunger]`.
